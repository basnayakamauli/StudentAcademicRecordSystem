# Student Academic Record Management System

A C# Windows Forms application developed to manage and display student academic records.

## Features

- Add student academic records
- Store Student ID, Student Name, Course, Unit and Marks
- Calculate unit GPA
- Calculate overall GPA
- Calculate current WAM
- Display student academic status
- Search for students by Student ID
- Display multiple unit records in a DataGridView
- Validate marks and required information
- Prevent duplicate unit records
- Display Satisfactory and At Risk student status

## Technologies

- C#
- .NET
- Windows Forms
- Visual Studio

## Application

The system provides a desktop GUI for entering, retrieving and displaying student academic information. Academic records are stored during the current application session.
